# 🤖 MentorAI
An AI-powered coding mentor with real-time streaming responses.

## Features
- Guest & Auth modes
- JWT authentication
- Chat history for logged-in users
- OpenAI streaming responses
- Markdown + code highlighting
- MongoDB persistence

## 🛠 Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB Atlas
- AI: OpenAI API
- Auth: JWT
